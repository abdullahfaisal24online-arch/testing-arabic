## 1. الدخول والحساب

- [ ] تسجيل حساب جديد
- [ ] تسجيل دخول ببيانات صحيحة
- [ ] رسالة خطأ ببيانات خاطئة
- [ ] استرجاع كلمة المرور
- [ ] تسجيل خروج، والرجوع لا يعيد الجلسة
- [ ] الجلسة بتضل شغّالة بعد إغلاق التطبيق وفتحه

## 2. المسارات الحرجة

<!-- عدّلها حسب منتجك — هاي أمثلة -->
- [ ] المسار الرئيسي من البداية للنهاية
- [ ] عملية الدفع / الإرسال / الحفظ
- [ ] الإشعارات بتوصل
- [ ] البحث بيرجّع نتائج صحيحة

## 3. البيانات

- [ ] إضافة عنصر جديد
- [ ] تعديل عنصر موجود
- [ ] حذف عنصر، والتأكيد قبل الحذف
- [ ] البيانات بتضل بعد إعادة التحميل
- [ ] القوائم الطويلة بتحمّل صح (pagination / scroll)

## 4. الحالات الفارغة والأخطاء

- [ ] شاشة فارغة أول استخدام برسالة واضحة
- [ ] انقطاع الإنترنت برسالة مفهومة
- [ ] خطأ من السيرفر ما بيوقّع التطبيق
- [ ] حقول إجبارية بتمنع الإرسال برسالة واضحة

## 5. الواجهة واللغة

- [ ] الاتجاه RTL سليم بكل الشاشات
- [ ] ما في نص مقطوع أو متجاوز حدوده
- [ ] الأرقام والتواريخ بالشكل المتوقّع
- [ ] الترجمة كاملة، ما في نص إنجليزي ظاهر بالخطأ
