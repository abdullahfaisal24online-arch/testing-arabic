هذا الدرس بيغطّي **الفصل الثاني** من منهج ISTQB CT-MAT — _Mobile Application Test Types_. الشرح بالفيديو، وهذا ملخّص سريع للفصل.

- **توافق الأجهزة**: الشاشة والدقّة، الحسّاسات (GPS، كاميرا، بصمة)، الذاكرة والمعالج، البطارية، وطرق الإدخال.
- **التفاعل مع نظام التشغيل والتطبيقات التانية**: المقاطعات، الأذونات، الإشعارات، الانتقال بين foreground و background، والمشاركة والروابط العميقة.
- **طرق الاتصال**: WiFi وبيانات الجوّال (3G/4G/5G) و Bluetooth و NFC، ضعف الإشارة، التبديل بين الشبكات، والوضع offline.
- **حسب نوع التطبيق**: Native (تكامل مع الجهاز)، Mobile Web (متصفّحات وأحجام شاشات)، Hybrid (الاثنين مع سلوك الـ WebView).
- **التوافق مع المنصّات والإصدارات**: أكثر من نظام تشغيل وأكثر من إصدار، التثبيت والترقية، وتناسق التجربة بين المنصّات.
