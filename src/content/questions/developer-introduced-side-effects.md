- **ليش بينسأل؟** لمعرفة فهمك لأهمية الـ Regression Testing وكيفية توثيق الأخطاء الناتجة عن التعديلات المتداخلة.
- **الجواب النموذجي:** إذا كان الخلل بنفس الـ Flow المباشر، يُعمل `Reopen` للتذكرة. إذا كان الخلل بميزة ثانية غير مرتبطة مباشرة، يُفتح `New Bug` ويوثّق بالخطوات والدلائل. مناقشة المطور بلطف لتوضيح أثر التعديل واقتراح إضافة Unit Test أو Component Test لمنع ارتداد المشكلة.
- **الفخ الشائع:** إهمال فحص الأجزاء المحيطة واكتفاء المتقدم بفحص الـ Bug المباشر فقط (Re-testing بدون Regression).
