- **ليش بينسأل؟** لتقييم درايتك بأدوات الفحص الساكن (Static Testing) المدمجة بالـ CI/CD Pipeline.
- **الجواب النموذجي:**
    - فحص الكود بدون تشغيله لاكتشاف المشاكل المبكرة قبل الـ Code Merge.
    - تحديد الـ Quality Gates التي تمنع دمج الكود الجديد إذا حوى ثغرات حرجة أو نسبة تغطية منخفضة.
- **الفخ الشائع:** اعتبار SonarQube أداة فحص واجهات وظيفية (Functional UI Testing) بدلاً من كونها أداة فحص كود ساكن.
