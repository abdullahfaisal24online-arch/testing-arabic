## جواب نموذجي

«بقرأ توثيق الـ API أول: شو المسارات، شو المعاملات الإجبارية، وشو رموز الاستجابة المتوقّعة.

بعدين بختبر بالترتيب: الحالة الناجحة، الحقول الناقصة، الأنواع الخاطئة، القيم الحدّية، والصلاحيات — هل يقدر مستخدم يوصل لبيانات غيره؟

وبتأكد من شكل الاستجابة نفسه مش بس رمزها، لأنه تغيير بالبنية بيكسر التطبيق حتى لو الرمز 200.»
