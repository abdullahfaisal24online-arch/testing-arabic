- **ليش بينسأل؟** للتأكد من درايتك بدورة حياة التيكيت ودورة العمل اليومية داخل فرق التطوير.

- **الجواب النموذجي**:نستخدم **Jira** لإدارة المشروع؛ حيث نقوم بمتابعة الـ Backlog، فتح الـ Bugs بروابط مباشرة للـ User Stories المتعلقة بها، وتحديث الـ Status حسب الـ Workflow المعتمد.التوثيق الشامل لمتطلبات الفحص والدليل الإرشادي للمشروع يتكامل غالباً مع **Confluence**.
- **الفخ الشائع:** الاكتفاء بذكر اسم الأداة دون توضيح كيفية ربط الـ Bug بالتيكيت الأصلية أو كيفية متابعة حالاتها بالـ Workflow.
