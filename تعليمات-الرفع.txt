========================================
تحسين الصور (WebP) — تعليمات الرفع
========================================

الفكرة باختصار:
سكربت بيشتغل وقت الـ build على Cloudflare، بيحوّل كل صور الـ covers
(PNG/JPG) لصيغة WebP تلقائياً، والكروت صارت تعرض WebP مع رجوع تلقائي
للـ PNG. بترفع كود بس — ولا صورة وحدة — والتحويل بصير للقديم والجديد
مع كل deploy.

----------------------------------------

----------------------------------------
طريقة الرفع عبر GitHub
----------------------------------------
1) فك ضغط الـ zip.
2) افتح الـ repo على GitHub  →  زر "Add file"  →  "Upload files".
3) اسحب المجلدات والملفات (scripts/ و src/ و package.json) داخل صفحة الرفع
   وهي محافظة على مساراتها. GitHub رح يستبدل الموجود ويضيف build-webp.mjs.
   (بديل: افتح كل ملف بالـ repo واعمل Edit والصق المحتوى الجديد — نفس النتيجة.)
4) رسالة commit مقترحة:  perf: WebP covers via build-time conversion
5) اعمل Commit  →  Cloudflare رح يبني وينشر تلقائياً.

----------------------------------------
بعد الـ Deploy
----------------------------------------
• بالـ build logs رح تلاقي سطر مثل:  [webp] تم: N محوّلة · … متخطّاة · … فاشلة
• افتح PageSpeed من جديد على testing-arabic.com وقارن النتيجة (خاصة Speed Index
  وحجم الصور).
• ما رح تحتاج ترفع أي صورة مستقبلاً — أي cover جديد بتضيفه بينحوّل لحاله.

----------------------------------------
لماذا هذا آمن
----------------------------------------
• ما في تعديل على package-lock.json، و sharp موجود أصلاً مع astro.
• لو غابت sharp لأي سبب، الـ build بيوقف (بيضل النسخة الشغّالة منشورة) بدل ما
  ينشر صور مكسورة.
• الكروت تستعمل <picture>: نسخة WebP أولاً، وإذا ما وُجدت يرجع للـ PNG.
