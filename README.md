# Testing بالعربي — المنصة

موقع تعليمي عربي (RTL) مبني بـ **Astro**، ثابت بالكامل، ومجاني الاستضافة.
المحتوى (دروس، مقالات، مسارات) بيتدار من **لوحة تحكم على الموقع** بدون كود، والفيديو مستضاف على **Bunny Stream**.

## 2. الإقلاع لأول مرة

### أ. ارفع المشروع على GitHub

1. أنشئ مستودع جديد باسم `testing-arabic` (خاص أو عام، الاتنين بيزبطوا).
2. ارفع محتويات هذا المجلّد كاملة (بدون `node_modules` و`dist`).

### ب. انشر على Cloudflare Pages (مجاني)

1. من لوحة Cloudflare: **Workers & Pages → Create → Pages → Connect to Git**.
2. اختر المستودع، وحط:
   - **Framework preset**: Astro
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
3. احفظ وانشر. رح يعطيك رابط مؤقت مثل `testing-arabic.pages.dev`.

بعد هيك، كل تعديل بينحفظ على GitHub بينشر تلقائياً خلال دقيقة تقريباً.

### ج. اربط الدومين

1. احجز الدومين (Cloudflare Registrar بيبيعه بسعر التكلفة تقريباً).
2. من صفحة المشروع على Pages: **Custom domains → Set up a domain**.
3. غيّر العنوان بثلاث أماكن:
   - `astro.config.mjs` → `site`
   - `src/consts.ts` → `SITE.url`
   - `public/robots.txt` → سطر `Sitemap:`

### د. فعّل لوحة التحكم

1. حقل `repo` في `public/admin/config.yml` معبّى مسبقاً بـ `abdullahqafaisal-cyber/testing-arabic` — غيّره فقط لو غيّرت اسم المستودع.
2. من GitHub: **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
   - **Repository access**: هذا المستودع فقط
   - **Permissions → Repository permissions → Contents**: `Read and write`
   - انسخ التوكن واحتفظ فيه بمكان آمن (ما بينعرض مرة تانية).
3. افتح `https://your-domain.com/admin/` واضغط **Sign In with Token** والصق التوكن.

> بتحب تسجيل دخول بضغطة زر بدل التوكن؟ انشر
> [Sveltia CMS Authenticator](https://github.com/sveltia/sveltia-cms-auth) على Cloudflare Workers،
> وشيل التعليق عن سطر `base_url` في `config.yml`.

### هـ. اربط Bunny Stream

1. أنشئ **Video Library** من لوحة Bunny.
2. انسخ **Library ID** واسم نطاق البث (`vz-xxxx.b-cdn.net`) وحطهم في `src/consts.ts`:
   ```ts
   export const BUNNY = {
     libraryId: '123456',
     cdnHostname: 'vz-xxxxxxxx-xxx.b-cdn.net',
   } as const;
   ```
3. لكل درس: ارفع الفيديو على Bunny، انسخ **Video ID**، وحطه بحقل "معرّف الفيديو" باللوحة.

### و. سجّل الموقع بجوجل

1. [Google Search Console](https://search.google.com/search-console) → أضف الدومين ووثّقه.
2. أرسل خريطة الموقع: `https://your-domain.com/sitemap-index.xml`.

## 3. الاستخدام اليومي

افتح `/admin/` واختر:

- **الدروس** — عنوان، رابط إنجليزي، وصف، تاريخ، تصنيف، مدة، معرّف فيديو Bunny، المسار وترتيب الدرس فيه، ملفات، ثم **الشرح المكتوب**.
- **المقالات** — نفس الفكرة، والنص كله ماركداون.
- **الدورات** — لتجميع الدروس بترتيب. الدرس اللي مش ضمن دورة بيضل ظاهر بمكتبة الدروس كفيديو متفرّق.
- **بنك أسئلة المقابلات** — كل سؤال بصفحته مع جواب مختصر وشرح، وفيه وضع تدريب بأسئلة عشوائية.
- **قاموس المصطلحات** — كل مصطلح بصفحته، وبينربط تلقائياً من داخل الدروس والمقالات.
- **الموارد والقوالب** — كل مورد بصفحته مع أزرار تحميل وشرح للاستعمال. الملفات نفسها بمجلّد `public/resources/`.
- **آخر الأخبار** — إعلانات وتحديثات.
- **الصفحات** — أي صفحة جديدة تنشئها بنفسك.
- **إعدادات الموقع** — اسم الموقع، القائمة، الدومين، Bunny، نصوص الصفحة الرئيسية، وصفحة «ابدأ من هنا».

اضغط **Publish** وبينحفظ على GitHub وبينشر تلقائياً.

> **أهم نصيحة للسيو:** حقل "الشرح المكتوب" هو اللي بيجيب الزيارات. جوجل ما بيقرأ الصوت —
> اكتب نص الدرس وخطواته وأكواده، مش بس سطرين وصف.

خانة **مسودّة** بتخلّي الدرس محفوظ بدون ما ينعرض على الموقع.

## 4. التشغيل على جهازك (اختياري)

```bash
npm install
npm run dev      # معاينة على http://localhost:4321
npm run build    # بناء نسخة الإنتاج في dist/
```

يحتاج Node.js نسخة 20 أو أحدث.

## 5. الصيانة والنسخ الاحتياطي

- **النسخة الاحتياطية**: المستودع على GitHub هو نسخة كاملة من كل المحتوى. الفيديوهات نسختها الأصلية عندك + على Bunny.
- **تحديث الحزم**: كل بضعة شهور `npm update` ثم `npm run build` للتأكد إنه كل شي تمام.
- **صورة المشاركة**: بعد ما تغيّر الدومين، شغّل `python3 scripts/make-og.py` لتحديث `public/og-default.png`.

## تفعيل النشرة البريدية

صناديق الاشتراك (بنهاية كل درس ومقال ومورد، وقسم النشرة بالرئيسية) **مخفية كلها** لحد ما تحط رابط النموذج:

1. أنشئ نموذج اشتراك على [Kit](https://kit.com) أو [Buttondown](https://buttondown.com) — الاتنين مجانيين لأول 1000 مشترك.
2. انسخ رابط الـ **action** تبع النموذج (مش رابط الصفحة).
3. حطّه باللوحة: **إعدادات الموقع ← إعدادات عامة ← رابط نموذج النشرة البريدية**.

أول ما تحطّه، بتظهر الصناديق كلها تلقائياً.


## القاموس والربط التلقائي

أي مصطلح تضيفه بقسم **قاموس المصطلحات** بينربط تلقائياً بأول ظهور له داخل متن الدروس والمقالات والموارد.

- حقل **الكلمات البديلة** هو المهم: حط فيه كل الصيغ اللي بتستعملها بالكتابة (ريجريشن، الريجريشن، Regression) وكلها بتنربط.
- الربط بيصير مرة وحدة لكل مصطلح بالصفحة، وما بيلمس العناوين ولا الأكواد ولا الروابط الموجودة.
- ما بتحتاج تعمل شي بالدروس — بس ضيف المصطلح وبينشتغل بالنشرة الجاية.

## الوسوم

أي وسم تضيفه لدرس أو مقال أو مورد بيصير إله صفحة على `/tags/<الوسم>/` بتجمع كل شي مرتبط فيه، وبتلاقي كل الوسوم على `/tags/`.

## وضع القراءة الفاتح

في مفتاح بالهيدر بيبدّل بين الغامق والفاتح، وبيتذكّر اختيار الزائر بمتصفّحه. الوضع الغامق هو الأساس.


## التمارين وتتبّع التقدّم

**التمرين:** بكل درس حقول «خطوات التمرين» و«خطوات الحل» و«كود الحل». عبّيها وبيظهر صندوق تمرين بنهاية الدرس، والحل خلف زر «اكشف الحل».

**تتبّع التقدّم:** الزائر بيقدر يعلّم الدرس كمنتهي، وبيشوف شريط تقدّم بصفحة الدورة، وبطاقة «كمّل من وين وقفت» بالرئيسية.

كل هذا محفوظ **بمتصفّح الزائر فقط** (localStorage) — بدون حسابات ولا قاعدة بيانات ولا أي تكلفة. يعني التقدّم ما بينتقل بين جهاز وجهاز، وهذا مقصود: صفر تعقيد وصفر بيانات شخصية.

## قواعد ثابتة — لا تتغيّر بعد الإطلاق

### شكل الروابط

| النوع | الشكل |
| --- | --- |
| درس | `/lessons/<slug>/` |
| دورة | `/courses/<slug>/` |
| مقال | `/articles/<slug>/` |
| خبر | `/news/<slug>/` |
| صفحة | `/<slug>/` |

رابط الدرس **مسطّح ومستقل عن الدورة** — يعني تقدر تنقل الدرس من دورة لدورة أو تخليه متفرّق بدون ما يتغيّر رابطه ولا تخسر ترتيبه بجوجل.

**قاعدة الـ slug:** حروف إنجليزية صغيرة وأرقام وشرطات فقط، ووصفي مش مختصر (`bug-report-that-works` أفضل من `lesson-4`). **لا تغيّر slug بعد النشر** — إذا اضطررت، احكيلي حتى نضيف تحويلة.

### المشغّل

Bunny Stream هو المشغّل الوحيد. حقل «رابط النسخة على يوتيوب» بيضيف رابط خارجي تحت الفيديو فقط، وما بيضمّن يوتيوب داخل الموقع.

### صفحة الدروس

أرشيف شامل: كل الدروس، اللي ضمن دورات واللي متفرّقة، مع شارة الدورة وفلتر.
